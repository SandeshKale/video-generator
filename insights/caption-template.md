# Caption template: Use It Today series (13 Oct 2026)

Every `caption.md` has these sections, in this order. Only the **Hashtags** section is allowed to repeat across reels; the rest is written fresh.

## 1. Caption (300–700 characters)
- **Line 1:** the comment-keyword CTA ("Comment REAL and I'll DM you ___ 👇") plus the topic words in plain language. The first line is what search and the viewer's "topic" classifier see, so it names the tool and the task ("ChatGPT", "resume", "scam call").
- **Lines 2–5:** what the reel shows, in short sentences. No repeat of the voice-over word for word.
- **Catch:** one honest limitation, if there is one.
- **Avatar disclosure line (always, same wording):**
  `🤖 Host: my AI avatar (a likeness of me, voiced by AI). The script, research and edit are mine; I use Claude to help build these.`
- **Sources line:** only tier-A sources, with the date read. Say "illustrative" for recreated UI.

## 2. Hashtags (top 5), a separate section
Exactly 5, picked with `insights/hashtag-research.md`, written as a table in `caption.md` (tag, role, why) and then as one line to paste. Put them in the caption itself, after the disclosure line, never as a first comment (Instagram's own guidance is about tags in the caption).

## 3. Not in the caption
First comment, alt text and the DM text go in their own files (`dm-prompt.md`).

## 4. YouTube Shorts posting sheet (required in every `caption.md`, added 16 Oct 2026)
Every reel's `caption.md` ends with a filled **"YouTube Shorts"** section so nothing is decided in Studio at upload time. Limits come from third-party summaries of YouTube's rules (read 16 Oct 2026): **verify each in Studio the first time**, then update this list.
- **Title** (≤100 characters; the first ~40 are what shows on mobile, so put the hook words first; no hashtag spam; write it in the video's language, Hindi in Devanagari or Hinglish, with the English topic words).
- **Description** (≤5,000 characters; only ~157 show before "Show more"): line 1 = the hook sentence + the topic words; then 2–4 short lines of what the video says; sources with dates (tier A/B named); the avatar disclosure line; credits/rights line for any stills; **3 hashtags** at the end (the first three are shown above the title; too many hashtags makes YouTube ignore them all). `#Shorts` is optional.
- **Tags** (hidden, ≤500 characters in total, comma-separated): film/title names, Hindi and English spellings, 10–15 tags. Low weight but free.
- **Visibility & schedule**: Public or Scheduled; give the IST time (evening 7–9 pm weekdays unless the data says otherwise) and the matching Instagram time.
- **Audience**: "No, it's not made for kids".
- **Altered or synthetic content**: **Yes** whenever the avatar (a realistic likeness of the creator, voiced by AI) or any realistic generated scene appears; write the exact answer in the sheet.
- **Category**: Entertainment (News & Politics only for pure news reels); **Language** = video language (Hindi) plus caption language (English burned-in; optional .srt upload).
- **Comments**: On (hold potentially-spam for review); **Pinned first comment** text (the CTA + sources link) ready to paste.
- **Playlist**: the series playlist (e.g. "Trailer reviews"); **Thumbnail**: for a Short, choose the strongest frame in the picker; note the frame time, since custom thumbnails are not reliably offered for Shorts.
- **Remixing / licence**: Allow remixing: off for footage-heavy reels (rights); Standard YouTube licence; **Paid promotion: No**; **Monetization/Content ID**: note the Content ID risk when trailer stills or poster art appear and keep the rights line.
- **Length/format check**: vertical 9:16, ≤3 minutes (Shorts limit since Oct 2024, per secondary sources), MP4 H.264/AAC, no burned-in third-party watermark.
- **Do-not-forget list**: remove the Instagram-only comment keyword CTA ("Comment X…") from the YouTube description and use "comment your guess / subscribe" instead; swap the Instagram handle block for the channel name; re-check every date and number the same day.
