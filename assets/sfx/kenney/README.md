Kenney CC0 sound effects from the GitHub starter kits (city builder: city ambience bed, placement/removal thuds, rotate, toggle; racing: engine, motorcycle engine, skid, impact).

(the racing kit's skid sound is by Landeplage, also CC0). The MIT file next to this README is the starter-kit *code* licence, not the audio.
Sources: https://github.com/KenneyNL/Starter-Kit-City-Builder , https://github.com/KenneyNL/Starter-Kit-Racing . Format: Ogg Vorbis (ffmpeg and Chromium decode it).
