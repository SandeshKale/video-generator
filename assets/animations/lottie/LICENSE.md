lottie-web, v5.13.0

Vendored file: lottie.min.js (full SVG-renderer build — supports
expressions, masks, and mattes; not the lighter `lottie_light` build,
which drops expression support some After Effects exports rely on).

Full text: https://github.com/airbnb/lottie-web/blob/master/LICENSE.md

Source: https://www.npmjs.com/package/lottie-web (https://github.com/airbnb/lottie-web)

Note: this vendors only the *runtime* that plays back a Lottie/Bodymovin
JSON export — it does not include any animation files. A reel using this
needs its own `.json` export from a motion designer (or a licensed
LottieFiles download), placed alongside that reel's build.mjs.
