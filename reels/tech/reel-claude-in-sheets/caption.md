Claude now works right inside Google Sheets, Docs and Slides. Messy data in; a clean table, a pivot table and a chart out. Here's the setup.

1️⃣ INSTALL: get "Claude for Google Workspace" from the Google Workspace Marketplace.

2️⃣ OPEN: in any sheet, go to Extensions → Claude → Open Claude. A Claude panel opens next to your data.

3️⃣ ASK it like you'd ask a colleague:
"Clean this up, total sales by month, and chart it."
In Sheets, Claude can write formulas, build pivot tables and native charts, and add new tabs. For joins or data cleaning, it can pull a range into Python and write the results back into the sheet.

By default it asks before every edit: each change shows up as an approval card, and nothing changes until you tap Approve. (There's also an "Accept all edits" mode if you'd rather it just go.) It can only open files your Google sharing already lets you open.

It works in Docs (fixes a sentence or restyles a heading in place) and Slides (builds new slides from your deck's own layouts and theme) too.

The catch:
⚠️ It's a public beta, so things can still change.
⚠️ It's on paid Claude plans only.
⚠️ On a work account, your admin may need to allow it first (on Team and Enterprise, an owner turns on the Docs, Sheets and Slides connectors).
