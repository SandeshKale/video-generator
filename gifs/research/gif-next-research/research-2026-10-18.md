## A. Prompt caching: "Don't break the cache" (recommended)
**Why it is hot and evergreen.** Every agent re-sends its system prompt, tool list and history on every turn. Caching that prefix is the biggest cost lever builders have. Every major provider ships it, and a January 2026 paper measured it on long agent runs. It stays relevant as long as LLM APIs exist, and it is architecture in the literal sense: the *order* of the prompt decides the bill.

**Facts (read 18 Oct 2026):**
| Fact | Tier | Source |
|---|---|---|
| The cached prefix is built in order **tools → system → messages**. "Cache hits require 100% identical prompt segments". "Changes at each level invalidate that level and all subsequent levels." | A | [Anthropic prompt caching docs](https://platform.claude.com/docs/en/build-with-claude/prompt-caching) |
| A cache read costs **0.1×** the base input price (0.05× on Opus/Sonnet 5.5, 0.025× on Fable/Mythos 5.1). A 5-minute write costs **1.25×**, a 1-hour write **2×**. The default 5-minute lifetime refreshes for free on each use. | A | same |
| Minimum cacheable length: 512 tokens on current Claude models (1,024–4,096 on older ones). | A | same |
| OpenAI: cached input discounted "up to 95%"; on GPT-5.6+ reads cost 0.1× and writes 1.25×. A prefix stays reusable "for 30 minutes after its most recent write or reuse". "Cache reuse requires the entire rendered prefix to match". "Put stable developer instructions and shared reference material first"; timestamps and user-specific text "at the end". | A | [OpenAI prompt caching guide](https://developers.openai.com/api/docs/guides/prompt-caching) |
| Lumer et al., *Don't Break the Cache* (arXiv 2601.06007, Jan 2026): 500+ agent sessions with 10,000-token system prompts. API cost **−41% to −80%**, time to first token **13–31% faster**. Strategic cache blocks (dynamic content at the end, dynamic tool results excluded) beat naive full-context caching, which "can paradoxically increase latency". | A (abstract) | [arXiv](https://arxiv.org/abs/2601.06007) |

**Relatable hook:** "Your AI agent pays for the same 10,000-token prompt on every turn. One timestamp in the wrong place is why."

**Metaphor options:**
1. **Pre-cast tower (recommended):** a building site. The foundation slabs (TOOLS, SYSTEM) are cast once and reused; each turn a crane adds one new floor (the new message) on top, and a meter shows "read 0.1×". Then a worker slips a "timestamp" brick into the foundation: the slab cracks, every floor above turns red and gets re-poured, and the meter jumps to "write 1.25×". Fix: the timestamp brick moves to the top floor, and the tower turns green again.
2. **Freight train:** a locomotive plus fixed coupled cars (the cached prefix) leaves the depot every turn; a new car is added at the back. Swap one car in the middle and the whole train is rebuilt in the yard.
3. **Printing press:** pre-set type plates for the stable text, with only the last line typeset fresh.
