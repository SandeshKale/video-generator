# Caption: "Teach your AI once." (reel-teach-a-skill, 61 s)

## Caption
You keep explaining the same thing to AI. Teach it once instead. 📇

A skill is a small instruction file Claude pulls out only when it's needed. Think of a library card catalogue: the label on the drawer is always visible, and the card inside only comes out when your request matches it.

Here's how to make your first one, in 4 steps:

1️⃣ PICK a task you've explained more than twice. Mine was my weekly team update.

2️⃣ ASK Claude: "Create a skill for my weekly team update." Then add three things: the format (wins, blockers, priorities, max 3 bullets each), the tone ("direct and factual, for my manager to skim") and one example you liked.

3️⃣ SAVE it, and switch it on in your Skills settings. In Claude Code, a skill is just a folder: ~/.claude/skills/weekly-team-update/SKILL.md

4️⃣ TEST it in a new chat. Look for "Reading weekly-team-update" in Claude's thinking. If Claude doesn't pick it up, sharpen the description.

The rule that makes it work: the description has to say WHAT the skill does and WHEN to use it.

Why you can keep dozens: until it's needed, each skill costs about 100 tokens (just its name and description). The instructions load only when triggered (under 5k tokens), and bundled files cost nothing until they're opened.

The catch:
⚠️ Code execution has to be on.
⚠️ Skills don't sync between apps: claude.ai, the API and Claude Code are separate.
⚠️ Only install skills you trust. A bad one can run code it doesn't mention.
🔒 Never put passwords or API keys in a skill.

Save this for when you set yours up, and follow for more AI how-tos.
